# Weather Mobile App 🌤️

## Descripción
Aplicación web mobile-first que muestra el tiempo actual, próximas horas y próximos días según la ubicación del usuario.

## Tecnologías utilizadas
- HTML5
- CSS3 (mobile-first)
- JavaScript (Vanilla)
- Open-Meteo API

## Instalación
1. Clonar el repositorio
2. Abrir `index.html` en el navegador
3. Aceptar permisos de geolocalización

## Funcionalidades
- Tiempo actual
- Previsión por horas
- Previsión diaria
- Diseño optimizado para móvil
